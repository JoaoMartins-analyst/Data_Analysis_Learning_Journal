## How I learn and use AI

1. Understand the concept and attempt a small example.
2. Give AI a bounded task with clear inputs, outputs and acceptance checks.
3. Compare its result with independently established examples or source totals.
4. Test a changed requirement or defective input.
5. Explain what I accepted, corrected and still cannot verify.

Independent assessments check my own understanding. For the Agent/API assessment, my built agent is the system being tested; a coding assistant does not repair its wrapper or tests for me.
