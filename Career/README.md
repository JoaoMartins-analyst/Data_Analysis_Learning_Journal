# Employment preparation

Prepare evidence for junior data analyst, reporting analyst/assistant, BI support and data operations roles. Later pipeline evidence can support engineering applications.

## Before the application milestone

- Prepare truthful CV/project explanations and accessible report previews.
- Research eligible roles and record exact skill, degree/experience, language and work-location requirements.
- Map requirements to actual project evidence and remaining gaps.
- Prepare a five-minute explanation in Portuguese and English.

Use the existing workbook's **Job Search** sheet for the live application/eligibility tracker. Do not publish personal contacts, application correspondence or private CV details in this repository.

## Application start

The current plan requires Phases 1/1B/2, PA1 and both the Python/analyst and Agent/API assessments. This is the user's selected preparation goal; individual employers may require a different skill set.

The workbook suggests 3–5 suitable applications per week after that milestone and a review after 20–30 eligible applications or four weeks. Outcomes depend on actual vacancies and eligibility.

The workbook's Hiring Evidence sheet contains dated and closed examples. Use it as a requirements reference, then verify each live advert before treating it as an application option.

## Project pitch notes

For each project, practise: question → source/grain → method → checks → result → limits → my contribution and AI assistance.
