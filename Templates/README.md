# Templates

Copy only the template needed for the current task. Replace prompts with actual work; do not submit empty templates as evidence.

| Template | Use |
|---|---|
| [Study session](study-session.md) | Questions, attempts, AI help, verification and next step |
| [Project brief](project-brief.md) | Decision, source, grain, scope and acceptance |
| [QA log](qa-log.md) | Data checks, cross-tool reconciliation and repairs |
| [AI work log](ai-work-log.md) | Bounded delegation and independent review |
| [Agent run](agent-run.md) | Actual calls, status, recovery and time comparison |
| [Assessment record](assessment-record.md) | Independent work, feedback, repair and status |
| [Business review](business-review.md) | Private pilot, revenue, costs, time and demand evidence |

Keep these source templates blank. Save filled copies in their relevant topic/project folder, or privately when they contain client information.
