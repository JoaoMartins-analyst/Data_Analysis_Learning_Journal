# Later progression

This is a parking place for the supplied roadmap's later stages. It does not add work to the current entry milestone.

| Stage | Development | Evidence |
|---|---|---|
| Phase 3 | PostgreSQL, transactions, measured query performance and repeatable ingestion | P2A |
| Phase 4 | dbt models, metric definitions, tests, lineage and history | P2B |
| Phase 5 | Docker, Airflow, recovery/backfills, CI and a small GCP/BigQuery comparison | P2C |
| Phase 6 | Permissions, restore, monitoring, changed requirements and engineering interviews | P2D + independent assessment |
| Optional Phase 7 | ML baseline, retrieval and deeper AI evaluation | P3A if selected |
| Optional Phase 8 | TypeScript interface, integrated AI service and hosted pilot | P3B/P3C if selected |

Keep P1 MySQL work intact when PostgreSQL begins. Reuse the early Python/API/validation work instead of repeating the same learning track.

The required early PA1 project is distinct from the optional advanced AI application. No TypeScript, React, RAG, multi-agent framework or PyTorch course is activated by creating this folder.

Create implementation folders only when one of these later stages is actually started. The detailed tasks and resources remain in the supplied workbook.
