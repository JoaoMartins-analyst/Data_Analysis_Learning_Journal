# PA1 — Unattended analysis assistant

**Status:** Not started. **Required for the chosen paid-work/application milestone.**

Extend the [Phase 2 utility](../analysis-utility/README.md). Queue one defined question before a shift; leave a checked analysis and findings draft for review afterwards.

## Required components

1. Actual local model API calls with model/version evidence.
2. Validated, allowlisted tools using the trusted calculation layer.
3. Approved input snapshots and defined output paths.
4. A scheduled job with run ID, persisted state and explicit status.
5. Time/call/usage limits, cancellation and duplicate protection.
6. Checked metrics, export, findings draft and review queue.
7. A failure/recovery runbook and comparison with the non-agent baseline.

SQL/Python generated by the model remains a draft for review. Do not execute arbitrary generated commands against client inputs.

## Three required unattended scenarios

| Scenario | Expected behaviour | Actual run evidence |
|---|---|---|
| Normal input | Validated metrics/export and a reviewable draft | Pending |
| Malformed data | Honest failure/needs-review status; no invented successful result | Pending |
| Interruption and restart | Safe recovery without duplicate output or lost state | Pending |

Also record the roadmap's fixed evaluation cases: empty data, duplicates, missing fields, wrong units, API timeout, bad arguments, malicious file instructions, cancellation and a limit reached.

Use the [agent-run template](../../Templates/agent-run.md) and [AI work log](../../Templates/ai-work-log.md). Raw traces stay private; public evidence is redacted.

## What passing means

Real model calls and observed scenarios are required. A mocked response, installed application or open chat session is insufficient.

The independent Agent/API assessment checks explanation, a changed tool/schema, failure diagnosis and controls. The built agent may run; a coding assistant may not fix the assessed implementation for you. Passing this project is separate from passing that assessment and the Python/analyst assessment.
