# Business analysis and statistics

**Roadmap placement:** Phase 1B and Phase 2; apply to every project.

- Define the owner, decision, period, row grain, metric and constraints before calculating.
- Distinguish sales, contribution and profit; compare fixed, variable and avoidable costs.
- Compare like periods, report sample size and uncertainty, and separate association from causation.
- Use selected descriptive, inference and regression exercises; explain the decision and its limits.
