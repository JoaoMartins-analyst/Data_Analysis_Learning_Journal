# Independent assessments

Keep the existing completed Weeks 1–4 Boss Battles and their repair history. Use the [assessment record](../Templates/assessment-record.md) for future gates.

| Assessment | Core demonstration | Imported status |
|---|---|---|
| Foundation / Month 1 Grand Boss Battle | Fresh Excel/SQL case; correct population/grain; three reconciliations | Pending |
| Phase 1B | Unfamiliar SQL/BI data, refresh/reconciliation and a defensible business decision | Not started |
| Phase 2 Python / analyst | Unfamiliar CSVs, useful tests, SQL reconciliation, uncertainty and explanation | Not started |
| Agent/API | Run, explain, modify and repair PA1; actual model calls, controls and recovery | Not started |

Ordinary assessments use a brief recall section followed by documentation, with AI assistance off. For the Agent/API assessment, the built agent is the system under test; independent explanation/debugging is still required.

The workbook uses 80% as a practice scoring target where applicable, with every critical failure repaired. A numeric score does not excuse materially wrong totals, silent lost data or an uncontrolled external action.

Record repairs and a changed-case retry after 3–7 days when required. Guided daily practice is not automatically a passed independent assessment.

Later Phase 3–6 and optional Phase 7–8 assessments stay in the workbook until those stages are activated.
