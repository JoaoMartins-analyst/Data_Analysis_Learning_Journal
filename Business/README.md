# Service development

Build one bounded restaurant-analysis service. Use the same checked work to improve delivery, create a truthful case study and support the employment portfolio.

## Current work

- Clarify the owner's one decision and inspect a small authorised dataset.
- Define inputs, outputs, deadline, acceptance checks and one revision boundary.
- Deliver the free pilot after relevant analysis checks.
- Record actual feedback and willingness to buy a specific next step.
- Start paid delivery after the chosen Phase 2 + Agent/API milestone.

The supplied business stretch goal is €10,000 revenue in one month within six months. Track that privately as revenue before costs/taxes, not profit, a forecast or a passed-study milestone.

Use the [business-review template](../Templates/business-review.md). Keep filled client/revenue/contact records in private storage or the private workbook. This public folder is for templates, generic service descriptions and approved/synthetic case-study lessons.

No paid price is pre-filled: scope, time and willingness to pay must be tested. Record collected cash separately from invoiced revenue and include review, revision, acquisition and administration time.

The [restaurant pilot](../Projects/restaurant-pilot/README.md) owns the delivery evidence. Link to it rather than duplicating project files here.
