## What the early agent must actually do

PA1 extends the tested analysis utility:

- Accept one queued question and an approved input snapshot.
- Call a real model API and only approved, validated analysis/export tools.
- Use deterministic code for exact calculations.
- Save outputs, checked metrics, a findings draft and a review package.
- Record run/state information and an explicit completed, failed or needs-review outcome.
- Demonstrate normal execution, malformed-data handling and interruption/recovery.
- Prevent uncontrolled calls, duplicate outputs and unapproved external actions.

Running locally is real API experience when actual model calls occur. It is not evidence of cloud deployment. Mock responses are useful test fixtures but cannot complete the real-model milestone.
