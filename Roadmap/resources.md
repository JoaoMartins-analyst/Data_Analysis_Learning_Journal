# Selected study resources

These links and IDs come from the supplied workbook. They were not freshly audited during this folder reorganisation. Use the specified sections and current phase; do not turn this index into a requirement to finish every course.

The main early sequence is existing Excel/SQL work, selected Microsoft Learn and business/statistics material, then the owned Mosh course with pandas/API/testing references. Use existing access and the current €0 additional subscription budget.

SQLBolt is already complete. pandas is now Phase 2. These current decisions override older resource-row descriptions.
