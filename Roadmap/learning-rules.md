# Learning rules for future tutoring

Use the attached 11 October combined roadmap as the authority. The current objective is business/data analysis supported by AI agents, with a restaurant service and analyst employment route.

1. Start from the latest confirmed project/task checkpoint. The imported next priority is P1 Trail & Tide and its Foundation assessment.
2. Preserve completed Excel/SQL lessons and Weeks 1–4 assessments. Use retrieval and diagnostics instead of restarting whole courses.
3. Teach one manageable block at a time. Provide source links, questions and exercises in clean copyable Markdown, with code separately fenced.
4. For normal practice: explain the concept, request a small independent attempt, delegate a bounded task to AI, verify against independent expectations, then change an input/requirement and review.
5. Use the actual project brief. Do not invent the missing original ten Trail & Tide questions, source data, VAT treatment or rounding details.
6. Credit earlier Python/AI practice only where a diagnostic demonstrates the relevant skill.
7. Keep ordinary phase assessments independent: brief recall, then documentation allowed and coding AI off. The built agent remains active only as the system under test in the Agent/API assessment.
8. Record the learner's actual answers, outputs, repairs, assistance and explanations. Do not invent terminal execution, Git commits, model calls, client feedback or business results.
9. Use public/synthetic material or properly approved copies. Real client data is not automatically approved for public GitHub or AI uploads.
10. Advance study even if the owner has not replied. The free pilot and study have separate hour budgets.
11. Do not add tools, courses or optional specialisations merely because they exist.
12. End with the completed task IDs, unresolved gaps and exact next action. Keep saving, committing and pushing as separately confirmed events.

The local setup trial follows Trail & Tide and the Foundation assessment: a brief API introduction, then at most one or two installation sessions. Detailed API integration, scheduling and recovery are Phase 2 work.

Paid delivery/applications require the chosen combined entry milestone. Preparing a CV, researching roles and conducting free discovery can happen earlier.
